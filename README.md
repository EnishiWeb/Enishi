# Enishi

自身のポートフォリオサイト「Enishi」のWordPressオリジナルテーマです。

制作会社様との業務委託を想定したポートフォリオとして、
デザインからコーディング、WordPressテーマ構築まで一貫して制作しています。

## コード設計について

実案件での運用や改修を想定し、
「後から見ても分かりやすく、変更しやすいコード」を意識して設計しています。

### PHP / WordPress

共通パーツとページ固有のパーツを分離し、
同じコードを繰り返し記述しない構成を意識しています。

ボタン・見出し・モーダルなど、複数箇所で使用する要素は
コンポーネントとして切り分けています。

また、トップページ・下層ページなどのページ固有パーツとは
ディレクトリを分け、各ファイルの役割が分かりやすくなるよう整理しています。

### SCSS

SCSSはFLOCSSの考え方を参考に、

- Foundation：サイト全体の基本設定
- Layout：ヘッダー・フッターなどのレイアウト
- Component：複数箇所で再利用するUI
- Project：ページ・セクション固有のスタイル
- Utility：汎用的な補助スタイル

に役割を分けています。

スタイルを1つのファイルにまとめるのではなく、
役割ごとに管理することで、修正時に影響範囲を把握しやすい構成を意識しています。

### JavaScript

JavaScriptは機能ごとにファイルを分割し、main.js から必要な処理を読み込む構成にしています。

アニメーションにはGSAP / ScrollTriggerを使用し、
単に動きを付けるだけではなく、操作性やコンテンツの見やすさを損なわない実装を意識しています。
